Laundry Wallah / Laundry Mart

A clean, foundational web page for Laundry Wallah / Laundry Mart, designed to showcase professional laundry and garment care services, transparent pricing, and an easy online booking form.

Overview

Laundry Wallah / Laundry Mart is a one-stop destination for convenient and hassle-free garment care. This web project serves as the main landing page for customers to explore available services, view pricing, and schedule a laundry pickup.

"You relax, we handle your laundry!"

Features

Welcome & Brand Introduction: Highlights the core mission, reliability, and convenience of the service.

Image Gallery: Showcases facility and service visuals (LAUNDRY1.jpeg, LAUNDRY2.jpeg, LAUNDRY3.jpeg).

Services Showcase: Detailed cards covering four main offerings:

Washing: Hygienic and fresh garment washing.

Dry Cleaning: Specialized care for delicate fabrics.

Ironing: Neat, wrinkle-free pressing.

Doorstep Delivery: Convenient pickup and drop-off service.

Transparent Price List: A structured HTML table displaying clear service rates in INR (Rs.).

Online Booking Form: Interactive form with built-in HTML5 validation for Name, Email, and a 10-digit Phone Number.

Contact Footer: Direct email support link (support@laundrymart.com).

Built With

HTML5: Semantic structure (<section>, <footer>, <form>, <table>) and native input validation.

Getting Started

Clone or Download the project files into a single folder on your local machine.

Ensure all referenced image assets (.jpeg and .png files) are placed in the root directory alongside index.html.

Open index.html in any modern web browser (Chrome, Edge, Firefox, Safari) to view the webpage.
